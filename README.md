# Proyecto con Flask
Una pagina web con Flask y diseño con estilo 
## Requisitos
- Python 3.12 o superior
- Git
## Instalación
1. Clona este repositorio: `git clone https://github.com/heidimichelle909-create/m2s1-ac1-entorno-flaskk/commits/main/`
2. Entra a la carpeta del proyecto: `cd viridi-proyecto-flask`
3. Crea el entorno virtual: `python -m venv .venv`
4. Actívalo: en Windows ; en macOS/Linux `source .venv/bin/activate`
5. Instala las dependencias: `pip install -r requirements.txt`
6. Crea tu archivo de configuración a partir del ejemplo: en Windows
`copy .env.example .env`; en macOS/Linux `cp .env.example .env`
## Ejecución
`python app.py`
Abre tu navegador en http://127.0.0.1:5000
